# 📊 Instruções para Execução do Projeto

Para que o código funcione corretamente, é necessário importar os arquivos CSV para o ambiente do Google Colab antes de iniciar a execução.

### 1. Baixe os arquivos necessários
Acesse a pasta do projeto no GitHub:
* **Caminho:** `Projeto3` ---> `documentos` ---> `Entrega 1` ---> `Projeto Interdisciplinar Ciência de Dados`
* Faça o download dos arquivos `.csv` principais que estão salvos nessa pasta (como o `Demonstrativo Fecap v3.csv`).

### 2. Abra o painel de arquivos no Colab
* No menu lateral esquerdo da tela do Google Colab, clique no **ícone de Pasta**.

### 3. Faça o Upload dos arquivos
* Clique no **ícone de upload** (o desenho de uma pasta com uma seta para cima ou uma folha com seta) ou simplesmente **arraste os arquivos `.csv`** do seu computador para dentro desse menu lateral do Colab.

### 4. Execute o código
* Aguarde a barra de carregamento dos arquivos terminar completamente.
* Depois disso, vá no menu superior em **Ambiente de execução > Executar tudo** (ou utilize o atalho correspondente).
